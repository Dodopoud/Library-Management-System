## Description

A Java console application that simulates a library management system.
Built from scratch as my first major Java project, focusing on OOP principles,
a clear separation of responsibilities and data persistence.

---

## Features

- Add, remove and search books
- Add, remove and search members
- Borrow and return books
- Automatic due date calculation (14 days)
- Overdue book detection
- Auto-generated unique IDs (B001, M001...)
- Data persistence using CSV files
- Input validation and error handling

---

## Technologies Used

- Java SE
- CSV file storage (BufferedReader / BufferedWriter)
- LocalDate for date handling
- OOP: encapsulation and separation of menu, logic and data classes

---

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Dodopoud/Library-Management-System
```

2. In Eclipse (or any Java IDE), create a new Java project and copy the contents of the `src` folder into it.
3. Run `Main.java`.
4. Log in with the demo
